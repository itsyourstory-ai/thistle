## Architecture decisions

### WizardLayout (layout route)
A new `src/pages/WizardLayout.tsx` wraps all `/step/*` routes as a React Router v6 layout (nested route with `<Outlet />`). It stays mounted across step navigation — this is where `useDraftPersistence` lives so the debounce timer and `draftId` survive step changes.

### DraftContext
A thin context (`src/contexts/DraftContext.tsx`) exposes `{ saveNow, dirty }` — provided by `WizardLayout`, consumed by `WizardHeader` for the "Save & exit" button. Keeps persistence concerns out of `WizardContext`.

### WizardContext additions
- `draftId: string | null` + `setDraftId` — persists across step navigation; set by resume flow before navigation; read by `useDraftPersistence` to decide INSERT vs UPDATE
- `resetWizard()` — clears both `answers` and `draftId`; called by "Create new book" on the dashboard

### Serialization
`src/lib/draftPhotos.ts` handles the base64 ↔ Storage conversion. What gets stripped before persisting:
- `answers.protagonist.photos[]` → replaced with `storage://` paths
- `answers.supportingCharacters[].photos[]` → replaced with `storage://` paths
- `answers.characterPortrait` → stripped entirely (regenerated by `useCharacterPortrait`)
- `answers.supportingPortraits` → stripped entirely
- `answers.appearanceAutofillHash` → stripped
- `answers.selectedConcept.coverImage` → stripped (the cover URL or data URL; regenerated at step 8)

Text fields (title, summary, story_seed, etc.) in `selectedConcept` are **kept** — re-generating a concept would lose the user's approved choice.

### Task 4 — useDraftPersistence hook
**Depends on:** Task 1, Task 3  
**Files:** `src/hooks/useDraftPersistence.ts`, `src/test/useDraftPersistence.test.ts`

Behavior:
- Read `user.id` from `useAuth()`, `answers` + `draftId` + `setDraftId` from `useWizard()`
- Watch `answers` with a 1500ms debounce; fire only when `answers.childName` is non-empty
- First save (no `draftId`): `supabase.from('book_drafts').insert(...)` → capture returned `id` → call `setDraftId(id)`
- Subsequent saves: `supabase.from('book_drafts').update(...).eq('id', draftId)`
- Payload: `{ user_id, answers: serialized, current_step: location.pathname, child_name: answers.childName, updated_at: new Date().toISOString() }`
- Return `{ saveNow, dirty }` where `saveNow` flushes immediately (bypasses debounce)
- Set `dirty = true` whenever `answers` change; set `dirty = false` after a successful save

**Tests:** mock Supabase client; assert debounce fires after delay; assert INSERT on first save + captures returned id; assert UPDATE on subsequent saves; assert `dirty` lifecycle.

export default function WizardLayout() {
  const { saveNow, dirty } = useDraftPersistence();

  useEffect(() => {
    if (!dirty) return;
    const handler = (e: BeforeUnloadEvent) => { e.preventDefault(); };
    window.addEventListener('beforeunload', handler);
    return () => window.removeEventListener('beforeunload', handler);
  }, [dirty]);

  return (
    <DraftContext.Provider value={{ saveNow, dirty }}>
      <Outlet />
    </DraftContext.Provider>
  );
}

### Task 13 — delete-account edge function
**Files:** `supabase/functions/delete-account/index.ts`

```ts
// Resolves user from the Authorization JWT header, then uses service_role
// to call auth.admin.deleteUser(). ON DELETE CASCADE on all user-owned tables
// handles data cleanup automatically.
import { createClient } from "npm:@supabase/supabase-js@2";

Deno.serve(async (req) => {
  const authHeader = req.headers.get("Authorization");
  if (!authHeader) return new Response("Unauthorized", { status: 401 });

  // Anon client — resolve the user from the JWT
  const anonClient = createClient(
    Deno.env.get("SUPABASE_URL")!,
    Deno.env.get("SUPABASE_ANON_KEY")!,
    { global: { headers: { Authorization: authHeader } } }
  );
  const { data: { user }, error } = await anonClient.auth.getUser();
  if (error || !user) return new Response("Unauthorized", { status: 401 });

  // Service role client — delete the user
  const adminClient = createClient(
    Deno.env.get("SUPABASE_URL")!,
    Deno.env.get("SUPABASE_SERVICE_ROLE_KEY")!
  );
  const { error: deleteError } = await adminClient.auth.admin.deleteUser(user.id);
  if (deleteError) return new Response(deleteError.message, { status: 500 });

  return new Response(JSON.stringify({ success: true }), {
    headers: { "Content-Type": "application/json" },
  });
});
```
